Rust, How complier manage Lifetime

September 11, 2025 · 3 min · 464 words · Me | Suggest Changes

Mostly people just use Lifetime, without understanding how the Lifetime implemention inside. So, I try to look in inside of binary and see how the rust implemention lifetime.

move value#

This is simple code that move Stringvalue into f function.

#[inline(never)]
fn f(value: String) {

    f(value);
}

Memory location#

  • 3 line: Call to alloc_shim, this is for make ready before allcate memory. (I’ll dive deeper into this in a future post.)
  • 4-6 line: Allocate 16 bytes of memory like malloc
  • 7-8 line: Check rax
    • If rax == 0 -> allocation failed -> jump to error handler

Load string#

  • 9-10:
    • load 16 bytes of data from .Lanon...5 (String)
    • Store into allocted memory

Calling f Function#

  • 11-13 line: Prepare arguments for f
    • [rsp] = 16
    • [rsp+8] = rax
    • [rsp+16] = 16
  • 14-15 line: Call f function
  • 16-17 line: Finish f function

Main function looks simuler with C main function binary. let’s look about f function binary too.

Func F#

   1   testRust::f:
   2    test    rdi, rdi
   3    je      .LBB4_1
   4    mov     rax, rdi
   5    mov     edx, 1
   6    mov     rdi, rsi
   7    mov     rsi, rax
   8    jmp     qword, ptr, [rip, +, _RNvCs73fAdSrgOJL_7___rustc14___rust_dealloc@GOTPCREL]
   9   .LBB4_1:
  10    ret

Memory Check#

  • Line 2-3:
    • Check if the pointer (rdi) is null.
    • If null -> jump to return

Prepare for Deallocation#

  • Line 4: Copy the pointer into rax.
  • Line 5: Set alignment or deallocation flag (depends on Rust allocator ABI)
  • Line 6: first argument for dealloc = layout (size/alignment info)
  • Line 7: second argument for dealloc = pointer to free

Call Deallocator#

  • Line 8: Call dealloc function

Now you can see how this String value moves.

  1. Allocate 16 bytes memory.
  2. Load String value from .Lanon...5.
  3. Save String to the Allocated memory.
  4. Jump into function f.
  5. End of function f, deallcate String value from memory.
